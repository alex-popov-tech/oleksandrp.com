03

From scratch

Six things that already existed, rebuilt to understand them

A Redis server that redis-cli can't tell apart

Speaks RESP over TCP with a goroutine per connection. Strings with expiry, streams, MULTI/EXEC transactions, WATCH, and leader-follower replication with WAIT.

Go · RESP · replicationRead the code

Git, byte-for-byte compatible

Reads and writes the real .git object store by hand and clones public repositories over Smart HTTP: pkt-line framing, packfiles, ref-delta chains, checkout.

Go · packfiles · zlibRead the code

A DNS server with no DNS library

Parses and serializes DNS packets byte by byte: bit-packed header flags, pointer-compressed names, recursive forwarding to an upstream resolver.

Go · UDP · name compressionRead the code

A BitTorrent client, magnet links included

Bencode, tracker announces, the peer wire protocol, SHA-1 verified pieces over a goroutine-per-peer work queue, and metadata fetched from peers over ut_metadata.

Go · peer wire · BEP 9/10Read the code

HTTP/1.1 on raw TCP

No net/http on the server side: request lines and headers carved out of the byte stream, chunked encoding with trailers, streamed files, reverse proxying, graceful shutdown.

Go · TCP · chunked encodingRead the code

grep, with a hand-compiled matcher

Patterns compiled into a token list and matched with backtracking search: classes, anchors, quantifiers, nested capture groups, backreferences, recursive file search.

Go · regex engine · CLIRead the code
